Chain reads and writes your task list directly from GitHub's API, using a personal access token stored only in this browser's local storage. Nothing is sent anywhere except api.github.com — this page is static and has no server of its own.

Create a token scoped to just this one repo at github.com/settings/personal-access-tokens/new — under "Repository access" choose Only select repositories and pick this one, then under "Permissions → Repository permissions" set Contents: Read and write. Leave everything else as No access. Pick a short expiration and re-issue it when it lapses.
